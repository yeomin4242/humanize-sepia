# 글 다듬기 기준

조건·인용·문장 구조를 바꾸며 뜻이 달라질 위험이 있을 때 확인한다. 수정 범위와 기본 표현 기준은 SKILL.md를 따른다.

## 보존할 내용

후속 수정은 새로 받은 글을 기준으로 하고, 새 글이 없으면 최근 완성문에 적용한다. 보호 구간은 원문에서 확인하고 줄 번호가 바뀌어도 내용을 유지한다. 타인의 직접 인용은 화자·문맥·출처와 표현을 보존한다. 사용자가 수정할 문장을 따옴표로 감싼 경우는 요청 범위에서 고친다.

누가 제안·결정·승인·실행했는지, 계획인지 완료인지, 의무인지 권고인지 확인한다. 수치가 같아도 대상·비교 기준이 달라지면 뜻이 달라진다. 일부 설명을 합치거나 삭제할 때 그 부분에만 있는 근거·예외·다음 행동을 남긴다.

| 원문 | 유지할 뜻 |
|---|---|
| 승인을 받으면 다음 달부터 적용할 예정이다. | 승인 조건과 아직 실행하지 않은 계획 |
| 문의가 줄었을 수 있지만 따로 측정하지 않았다. | 추정과 측정의 한계 |
| 담당자의 확인이 없는 요청은 처리하지 않는다. | 부정과 적용 조건 |
| 검토 결과를 팀장에게 전달했다. | 전달한 행동의 범위 |

## 문장 구조

주어를 밝히거나 피동을 바꿀 때 자료에서 확인되는 주체만 쓴다. 긴 수식어는 대상 가까이에 두거나 문장으로 나눈다. “요청이 있으면 확인하고 회신한다”를 나눌 때도 두 행동에 걸린 조건을 남긴다. 같은 대상을 가리키는 용어는 일관되게 쓴다.

## 최종 점검

새 문장을 원자료·최신 요청과 대조하고 수정 직전본의 필요한 근거와 말투를 확인한다. 일부 수정에만 문제가 있으면 해당 부분을 복구한다. 추가 표현을 빼거나 원래 표현으로 돌렸을 때 더 명료하면 덜어 내거나 되돌린다. 짧아진 양을 개선의 근거로 삼지 않는다. 뜻을 확정할 수 없으면 해당 문장과 필요한 정보를 밝힌다.
