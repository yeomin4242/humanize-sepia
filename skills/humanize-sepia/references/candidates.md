# 서로 다른 글 비교하기

쓸 내용이나 설명 순서에 따라 글의 전달력이 달라질 때, 같은 자료로 완성문을 비교한다. 요청이 허용한 범위 안에서 한 편을 선택하거나 각 글의 장점을 살려 다시 쓴다.

## 비교가 필요한 경우

작성이나 구성 수정에서 핵심 주장·쓸 근거·설명 순서가 달라질 수 있거나, 사용자가 여러 안을 요청했을 때 적용한다. 방향이 분명한 짧은 글은 바로 쓴다. 표현만 고치는 요청은 해당 구간을 다듬고, 검토만 요청하면 진단을 제공한다.

같은 자료·독자·목적·말투·분량 조건으로 비교한다. 최신 요청과 원자료를 사실의 기준으로 두며, 기존 글을 고칠 때는 원문도 비교 대상에 남긴다. 사용자가 고른 경험과 보호한 내용은 유지한다.

## 실제로 다른 완성문 만들기

비교할 두 방향을 정해 각각 끝까지 쓴다. 한 글은 판단을 먼저 보여 주고 다른 글은 판단에 이른 문제를 먼저 보여 줄 수 있다. 서로 다른 근거를 중심에 놓거나, 여러 행동을 공통 배움으로 묶는 방식과 중요한 한 행동을 자세히 설명하는 방식을 비교할 수도 있다. 그 차이가 이번 목적에 의미가 있을 때만 사용한다.

첫 글의 단어를 바꾸는 데 그치지 않고, 각 방향에서 필요한 근거와 연결을 갖춘 본문을 만든다. 대안 수를 채우려고 약한 글을 일부러 만들거나 사용자가 원하는 방향과 어긋난 주장을 세우지 않는다. 초안이 이미 충분하면 그대로 둘 수 있다.

별도 작성 문맥을 사용하도록 요청받았다면 각 문맥에 같은 요청·원자료·필요한 선호만 제공한다. 같은 문맥에서 쓴 대안은 독립 생성이라고 보고하지 않는다. 일반적인 사용에 별도 에이전트나 추가 모델 호출을 필수로 두지 않는다.

## 한 편 선택하기

각 글을 설명 없이 본문으로 읽는다. 필요한 사실과 명시 조건을 확인한 뒤 다음 차이가 실제 문장에서 보이는지 비교한다.

- 독자가 알아야 할 핵심이 무엇이며 어떤 근거가 이를 설명하는가?
- 행동의 대상·선택 기준·이유가 이해되는가? 활동 나열이나 자기 칭찬이 설명을 대신하는가?
- 앞뒤 내용이 이어지는가? 배경과 반복이 핵심을 가리는가?

이번 목적에 더 잘 맞는 글을 선택하고, 선택을 좌우한 구간과 이유를 짧게 잡는다. 이 메모는 작업 중에 사용하며 요청하지 않으면 출력하지 않는다. 길이·화려함·포함한 사실의 수·자체 점수만으로 선택하지 않는다. 차이가 작으면 충분한 기존 글을 쓴다.

## 장점을 살려 다시 구성하기

각 글에 서로 다른 유효한 장점이 있고 그 장점을 함께 쓰면 설명이 더 분명해질 때 시도한다. 한 편이 이미 충분하면 선택한 글로 끝낸다.

선택한 글의 핵심을 기준으로, 다른 글에서 가져올 근거나 연결과 덜어 낼 내용을 정한다. 후보의 문장을 이어 붙이기보다 **원자료를 보며 하나의 흐름으로 다시 쓴다.** 각 글의 도입·배움·결론을 모두 남길 필요는 없다. 다른 경험과 역할, 서로 다른 조건을 합쳐 새로운 사건이나 인과를 만들지 않는다. 후보에만 등장하는 사실은 원자료로 확인하기 전까지 근거로 쓰지 않는다.

새 본문과 선택한 글을 같은 분량 조건에서 비교한다. 필요한 설명이 분명해지고 근거·말투·조건이 유지된 쪽을 쓴다. 다시 쓴 글에 반복·과장·새 사실이 생기거나 차이가 없으면 선택한 글로 돌아간다. 기존 글 수정에서는 원문도 다시 확인한다. 비판적 개선의 반복 여부는 [비판과 반복 수정](improving.md#끝내기)를 따른다.

## 결과 보여 주기

본문만 요청하면 최종 글 하나만 보여 준다. 여러 안을 보여 달라는 요청에는 각 안을 그대로 제공하며, 하나로 합치는 요청이 없으면 비교 과정을 이유로 합치지 않는다. 요청한 수정 범위와 출력 형식이 우선이다.

여러 후보를 썼다는 사실이나 모델의 선택 이유는 작문 우위의 증거가 아니다. 실제 독자의 선택과 AI의 비교를 구분해 설명한다.
