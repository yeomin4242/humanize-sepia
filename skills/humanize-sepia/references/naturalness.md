# 자연스러운 표현

AI 티·상투적 표현·기계적 반복의 점검이나 문체 대조를 요청할 때 읽는다. 사실·수정 범위·출력·종료 기준은 SKILL.md를 따른다.

## 문장에서 하는 일로 판단하기

단어 하나, 세 항목 나열, 일정한 문장 길이는 작성 주체의 증거가 아니다. 특정 표현을 쓰지 않아야 한다는 규칙보다 그 구간이 독자의 이해를 어떻게 방해하는지 확인한다. 명료한 문장은 그대로 둔다.

| 살필 구간 | 고칠 때 | 남길 때 |
|---|---|---|
| 부사·강조 | “진정으로”, “효과적으로”가 같은 말을 부풀리면 덜어 내거나 확인된 행동으로 표현 | “직접”이 본인의 역할을, “처음”이 시점을 구분하는 경우 |
| 나열·어휘 반복 | 비슷한 역량 이름이나 같은 뜻을 중복하면 묶기 | 실제 세 가지 요건·단계, 동일 개념을 가리키는 전문용어 |
| 연결어·대조 | “또한”, “더불어”, “이를 통해”가 관계를 설명하지 못하면 삭제하거나 자료에 있는 관계로 연결 | 실제 추가·대조·인과를 전달하는 연결, 조건·예외를 구분하는 대조 |
| 문장·문단 구조 | 같은 시작·설명·다짐이 반복돼 핵심을 가리면 중복 설명을 합치고 필요한 근거에 분량 배분 | 비교표·병렬 요건의 일관된 구조, 작성자가 의도한 반복 |
| 마무리·도입 | 앞말을 다시 칭찬하거나 본론을 예고만 하면 덜어 내기 | 필요한 맥락, 문항의 필수 포부, 독자에게 필요한 다음 행동 |

문장을 짧게 만드는 양보다 무엇이 더 잘 전달되는지로 수정 효과를 판단한다. 리듬을 바꾸려고 문장을 무작위로 끊거나 동의어를 돌려 쓰지 않는다. 주체가 확인되지 않은 피동문은 행위자를 만들어 능동문으로 바꾸지 않는다.

## 문체와 글의 용도

예전 글을 제공받으면 이번 글과 가까운 짧은 구간에서 어휘·문장 길이·격식·연결 방식만 참고한다. 담담함·유머·망설임·솔직한 감상은 실제 자료에 있을 때 살린다. 사람답게 보이려는 새 감정·경험·구어체·오탈자는 넣지 않는다. 무난한 표현으로 고치면서 고유한 말투와 필요한 긴 문장까지 없애지 않는다.

연구 글의 “가능성이 있다”, “아직 검증되지 않았다”, 조사 대상·오차·한계는 주장 강도의 일부다. 겹친 완곡어만 정리하고 가설을 결과로 바꾸지 않는다. 제안서는 승인·적용 조건과 예정 시점을 유지한다. 용도별 작성은 [채널 적용](channels.md)을 따른다.

본문에 섞인 작성 메모는 작업에 반영하되 완성문에 되풀이하지 않는다. 직접 인용·고유명·코드·경로·링크 대상은 스타일 점검에서 보호한다. 사용자가 고칠 대상으로 지정한 인용 형태의 초안은 요청 범위에서 수정한다.

검토에서는 해당 구간·읽기에 생기는 문제·가능한 수정 방향을 연결한다. 선택 가능한 문체 차이는 오류와 구분한다. AI 확률이나 자체 자연스러움 점수로 수정을 강제하지 않는다. 수정표나 진단을 먼저 보여 달라고 요청한 경우에만 그 형식으로 제공한다.
