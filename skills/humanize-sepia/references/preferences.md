# 수정 취향 활용

사용자가 실제로 채택한 수정·수정 이유·참고하라고 제공한 글을 선택 기준으로 쓴다. 자료가 없으면 현재 요청으로 작성한다. 모델의 예시나 채택하지 않은 출력은 개인 취향의 증거가 아니다.

거절한 문장·채택한 문장·선택 이유를 함께 읽어 강조한 행동, 설명 순서, 생략, 주장 강도의 차이를 살핀다. 이유가 없으면 확인된 차이만 참고한다. 한 번의 선택을 모든 글에 적용할 취향으로 확정하지 않는다.

이번 목적과 관련 있는 기준만 적용하며 현재 요청이 우선한다. 참고 글의 문장을 복제하거나 사건·수치·감정·성과를 현재 경험으로 옮기지 않는다. 사용자가 선호하는 말투와 근거의 설득력은 따로 확인한다.

기록을 만들거나 갱신해 달라는 요청이면 지정한 경로에 독자·목적·근거 문장·수정 이유·적용 범위만 남긴다. 개인 경험 전체를 공통 스킬에 넣지 않는다. 제공된 대화·기록 밖의 취향을 알고 있다고 표현하지 않으며 설치만으로 다른 대화의 수정이 자동 저장되거나 학습되는 것은 아니다.
