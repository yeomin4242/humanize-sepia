# 수정에서 작성 기준 정리하기

사용자가 실제로 채택한 수정·수정 이유·참고하라고 제공한 글을 활용한다. 자료가 없으면 현재 요청으로 바로 작성한다. 모델의 예시나 채택하지 않은 출력은 개인 취향의 증거가 아니다.

거절한 문장·채택한 문장·선택 이유에서 강조한 행동, 설명 순서, 생략, 주장 강도의 차이를 살핀다. 이번 글에 맞는 기준 몇 개만 짧게 추리고, 필요한 경우 이를 보여 주는 한 구간을 함께 참고한다. 이유가 없으면 확인된 차이만 사용하며 한 번의 선택을 모든 글의 취향으로 확정하지 않는다.

독자·목적·수정 범위가 맞는 기준을 사용하고 현재 요청을 우선한다. 참고 글의 문장·사건·수치·감정·성과를 현재 경험으로 옮기지 않는다. 말투가 취향에 맞는지와 내용이 설득력 있는지는 따로 확인한다. 간단한 작성에는 별도 선호 분석·예시 생성·후보 비교를 붙이지 않는다.

## 재사용할 기록을 요청한 경우

다음 항목으로 짧게 남긴다. 선택 이유가 제공되지 않은 부분은 추측으로 채우지 않는다.

- **적용할 글:** 독자·목적·수정 범위.
- **작성 기준:** 무엇을 강조하거나 덜어 낼지.
- **근거:** 실제 선택한 문장과 이유. 거절한 문장이 있으면 필요한 부분만 함께 남긴다.
- **적용 범위:** 다른 목적에는 그대로 옮기지 않을 조건.

여러 기록이 있으면 새 수정과 관련된 기준만 갱신한다. 이미 확인한 이력 전체를 매번 다시 분석하지 않는다. 글 작성 시에는 관련 기준과 짧은 근거만 재사용하며, 준비·갱신 작업과 새 글 작성은 구분한다.

파일 저장을 요청하면 지정한 경로에 남긴다. 개인 경험 전체를 공통 스킬에 넣지 않는다. 제공된 대화·기록 밖의 취향을 알고 있다고 표현하지 않으며 설치만으로 다른 대화의 수정이 자동 저장되거나 학습되는 것은 아니다.
