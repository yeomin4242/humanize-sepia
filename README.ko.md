# Humanize Sepia

[English](README.md) · [한국어](README.ko.md)

**전하고 싶은 내용을 자연스러운 한국어 글로 정리합니다.** 경험과 메모에서 쓸 내용을 고르고, 생각이 잘 이어지도록 문단을 구성하며, 내 말투를 살려 문장을 다듬습니다. 자기소개서는 지원 회사와 직무를 고려해 문항이 무엇을 확인하려는지 읽고, 그에 맞는 경험을 글로 풀어냅니다.

현재 버전은 **0.1.0**입니다. 지침과 예시는 한국어를 중심으로 작성돼 있으며, 필요한 작성 기준은 `humanize-sepia` 폴더 안에 포함돼 있습니다.

## 하는 일

| 모드 | 용도 |
|---|---|
| `write` | 쓰고 싶은 내용과 경험, 메모를 바탕으로 새 글 쓰기 |
| `refactor` | 내용·말투·글의 순서를 유지하면서 문장 다듬기 |
| `review` | 글은 그대로 두고 어색하거나 보완할 부분 짚기 |
| `recreate` | 요청한 경우, 내용과 의도를 살려 구성을 새로 잡고 다시 쓰기 |

문항의 단어를 하나씩 되풀이하는 대신, 평가자가 판단할 수 있는 행동과 근거를 고릅니다. “다른 시각”을 묻는다면 무엇을 다르게 보았고 왜 그 방법을 택했는지 보여 줄 수 있습니다. 분량·사례 수·필수 하위 질문처럼 명시한 요구는 지킵니다.

보여 주고 싶은 역량과 실제로 한 행동을 구분하고, 본인의 행동·타인의 승인·팀 성과의 범위를 유지합니다. 중요한 사실이 부족하면 필요한 부분만 묻거나 잠정 초안을 제공합니다. 보완 안내는 자기소개서 본문 밖에 둡니다.

## Codex 설치

Codex에서 다음과 같이 설치를 요청하세요.

```text
$skill-installer https://github.com/yeomin4242/humanize-sepia/tree/main/skills/humanize-sepia
```

직접 전역 설치하려면 저장소를 받은 뒤 스킬 폴더를 복사합니다. 같은 이름의 `humanize-sepia` 폴더가 이미 설치돼 있다면 먼저 다른 위치에 백업해 두세요.

```bash
git clone https://github.com/yeomin4242/humanize-sepia.git
mkdir -p ~/.agents/skills
cp -R humanize-sepia/skills/humanize-sepia ~/.agents/skills/
```

프로젝트에서만 쓰려면 해당 프로젝트의 `.agents/skills/humanize-sepia`에 스킬 폴더를 넣습니다.

## 사용법

`$humanize-sepia`로 호출하고 자료를 자유롭게 붙여 넣으세요. 기업 소개·직무·문항·쓰고 싶은 방향·경험·초안이 섞여 있어도 됩니다. **정해진 순서나 필수 항목명은 없습니다.** “쓰고자 하는 방향” 한 항목으로 적어도 되고, 제목 없이 이어 써도 됩니다.

아래 기업과 경험은 사용법을 보여 주기 위한 가상 예시입니다.

```text
$humanize-sepia

소규모 판매자들이 이용하는 온라인 장터의 운영 직무에 지원하려고 해.
판매자 문의에 답하고, 자주 생기는 불편을 찾아 개선하는 일이래.
자소서에서는 익숙한 방식에서 벗어나 문제를 해결한 경험을 묻고 있어.

매장에서 아르바이트할 때, 직원마다 안내가 달라서 손님이 같은 질문을
다시 하는 일이 있었어. 자주 들어오는 질문과 답을 표로 정리했고,
매니저가 확인한 뒤 교대 근무하는 동료들과 함께 쓰기 시작했어.
동료들은 답을 찾기 편해졌다고 했어. 같은 질문이 얼마나 줄었는지는
따로 세어 보지 않았고.

직원마다 안내가 달랐다는 점에 주목하고 해결한 경험을 쓰고 싶어.
초안에는 “남다른 관찰력으로 혁신적인 개선을 이루었다”고 썼는데,
좀 거창하게 느껴져. 내가 한 일이 잘 드러나도록 자연스럽게 써줘.
공백 포함 500자 이내로, 담담한 말투면 좋겠어.
```

초안이 있다면 함께 보내 주세요. 살릴 문장과 말투는 유지하고, 전달하고 싶은 내용에 맞춰 글을 완성합니다. 뜻이나 중요한 사실이 달라질 수 있는 부분은 확인합니다.

기존 글을 다듬거나 살펴보고 싶다면 이렇게 요청할 수 있습니다.

```text
$humanize-sepia 내용과 말투는 그대로 두고, 어색한 문장만 다듬어줘.
숫자와 인용문은 바꾸지 말아줘.
글: …
```

```text
$humanize-sepia 글은 고치지 말고, 어디가 어색하거나 부족한지 알려줘.
글: …
```

```text
$humanize-sepia 하고 싶은 말과 실제 있었던 일은 유지해줘.
글의 구성부터 새로 잡아서 처음부터 다시 써줘.
글: …
```

기본은 본문을 먼저 보여 주고, 중요한 수정 이유나 확인 사항만 짧게 덧붙입니다. 사용자가 지정한 출력 형식이 우선입니다. 작성자는 본인의 사실을 확인해야 하며, AI 탐지기 점수를 글의 완성 기준으로 삼지 않습니다.
